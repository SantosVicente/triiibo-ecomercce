# triiibo-ecomercce

## Breve descrição

triiibo-ecomercce é um repositório para o projeto de um e-commerce de Engenharia de Software com foco em artigos de acampamento. O objetivo é documentar requisitos, UX/UI, fluxos de negócio, testes e um backlog priorizado para implementação incremental (sprints).

## Arquivos e pastas (atuais e previstas)

- [README.md](README.md)
- `docs/` — documentação complementar, requisitos, narrativas e plano de testes.
- `design/` — diagramas (UML, casos de uso), wireframes e arquivos do Figma/Draw.io.
